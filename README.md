\# AI-Based Smart Attendance Management System Using Face Recognition



An AI-based smart attendance management system that automates student attendance using face recognition technology. The system provides student registration, face image capture, face training, automated attendance marking, and attendance record management through a user-friendly graphical interface.



\## 📌 Project Overview



Traditional attendance systems can be time-consuming and require manual record keeping. This project was developed to automate the attendance process using computer vision and face recognition.



The system allows a student to be registered with their enrollment number and name, captures facial images, trains the face recognition model, and later identifies registered students to mark their attendance automatically.



\## ✨ Features



\- Student registration

\- Enrollment number and name management

\- Face image capture

\- Face recognition-based attendance

\- Face training

\- Subject-wise attendance

\- Automatic attendance marking

\- Manual attendance option

\- Attendance record viewing

\- Attendance data management

\- Graphical user interface

\- Text-to-speech support
